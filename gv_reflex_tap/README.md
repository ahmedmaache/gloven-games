# Startup Reflex

A reaction time testing game for Global Ventures founders.

## 🎮 Gameplay
- A target appears at random positions
- Tap it as fast as you can!
- 10 rounds per game
- See your average and best reaction times

## 🚀 Quick Start
```bash
cd gv_reflex_tap
flutter pub get
flutter run
```

## 🎨 Customization
See `founder_customization.md` for detailed instructions on:
- Changing colors and text
- Replacing icons with your logo
- Updating app name and package name

## 📦 Building for Release
```bash
flutter build appbundle
```
