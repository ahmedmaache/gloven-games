# Startup Match-3 Puzzle

A simple, policy-safe Match-3 game for Global Ventures founders.

## 🛠 Project Setup
1. **Name**: `gv_match3`
2. **Platform**: Android (Target SDK 34 recommended)
3. **Permissions**: NONE (Offline only)

## 🎨 Branding
Edit `lib/config.dart` to change:
- `startupName`
- `appTitle`
- `primaryColor`
- `tileColors`

## 📦 Publishing Checklist
1. **Package Name**: Change `com.gloven.startup.gv_match3` to your own (e.g. `com.logistics.puzzle`).
2. **Icon**: Replace `android/app/src/main/res/mipmap-*`.
3. **Play Store Data Safety**:
   - Does this app collect data? **NO**.
   - Is it encrypted? **N/A**.
   - Can users request deletion? **N/A**.
