# Swipe Avoider

A 3-lane obstacle dodging game for Global Ventures founders.

## 🎮 Gameplay
- Player starts in center lane
- Swipe left/right (or tap sides) to switch lanes
- Dodge falling obstacles
- Score increases for each obstacle passed
- Speed increases over time!

## 🎨 Customization

Edit `lib/config.dart`:
- `startupName` - Your startup name
- `appTitle` - Game title
- `primaryColor` / `secondaryColor` - Brand colors
- `playerColor` - Player circle color
- `obstacleColor` - Obstacle color
- `baseObstacleSpeed` - Starting speed
- `speedIncrement` - How much faster it gets

## 📦 Building for Release
```bash
flutter build appbundle
```
